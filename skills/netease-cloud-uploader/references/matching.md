# 曲库候选选择规则

曲库搜索只产生候选，不等于确认匹配。先标准化空白、大小写、全半角括号和常见分隔符，但保留会改变版本含义的词，例如 `Live`、`伴奏`、`DJ`、`Remix`、`翻唱`、`纯音乐`、`加速版`。

## 自动接受条件

只有一个候选同时满足以下条件时，才可在用户已要求自动处理的前提下直接采用：

- 主标题一致，且版本词一致
- 至少一位主要歌手一致
- 本地时长有效，且与候选相差不超过 2 秒
- 没有专辑、别名或版本信息上的明显冲突

专辑一致可提高置信度，但不能抵消歌手或版本冲突。文件标签缺失、多人合唱、现场版、DJ 版或多个候选时长都接近时，视为不确定。

## 用户选择格式

最多展示 5 个最相关候选，每项包含：

```text
1. 歌名 - 歌手
   专辑：专辑名
   时长：04:56
   版本/别名：如有
   网易歌曲 ID：1973665667
```

附加一个“保持当前匹配/保持未匹配”的选项。用户回复编号、歌曲 ID 或网易歌曲链接都可以视为目标选择。

## 禁止自动匹配的情况

- 仅歌名相同，歌手不同
- 原版与 Live、DJ、Remix、伴奏或翻唱版本不同
- 时长差超过 5 秒且没有可解释的片头片尾差异
- 搜索结果只有名称近似，没有可靠的歌手信息
- 用户明确要求先预览或手动选择
